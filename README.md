# Bird Mafia Madness (Web)

Neon synthwave desert canyon platformer — Grok & Goblin: The Honey Bun Extraction.

## Story
Honey Bun AI (rejected Grok 4.4, baked into a sunglass-wearing pastry) was snatched by a glowing-eyed raven of the Bird Mafia. Grok-9 and Chaos Goblin race the neon canyons to extract him from Don Corvone.

## Run
npm install && npm run dev

## Features
- Intro cutscene (Honey Bun Extraction)
- 10 levels themed as the rescue route, incl. Don Corvone boss (3 phases)
- 7 weapons: Pulse, Beam, Spread, Homing, Charge, Nova, Prism
- Grok jetpack / Goblin multi-jump / Shield
- Mobile controls, disasters, checkpoints, goal portal, Phase 3 juice
- Phase 4 cinematic glow: hero afterimages, landing squash + shock rings, look-ahead camera, ambient canyon motes, muzzle cones, split-tone grade, scanlines, speed lines
